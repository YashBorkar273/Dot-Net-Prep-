## Why this matters
Full-stack interviews almost always open the frontend round with JS fundamentals.

## Topics to cover
- [ ] let/const/var, scope and hoisting
- [ ] Closures and `this` (arrow functions vs regular functions)
- [ ] Promises, async/await and the event loop
- [ ] ES modules
- [ ] TypeScript: types vs interfaces, union types, generics, strict mode, type narrowing

## Interview check: you must be able to answer
- What does `this` refer to inside an arrow function vs a regular function?
- Explain the event loop: why does a resolved promise callback run before a setTimeout(0)?
- Type vs interface in TypeScript: when does it matter?
- What does strict mode in tsconfig catch for you?
