## Why this matters
Most full-stack bugs live at the browser/API boundary.

## Topics to cover
- [ ] Semantic HTML and forms
- [ ] CSS box model, flexbox, grid basics
- [ ] How the browser makes HTTP requests
- [ ] CORS: what it protects, preflight requests
- [ ] Cookies vs localStorage vs sessionStorage for tokens
- [ ] XSS and CSRF in SPAs

## Interview check: you must be able to answer
- Your Angular app gets a CORS error calling your API. Which side do you fix, and why?
- Where would you store a JWT in the browser, and what's the risk of each option?
- What is a preflight request and when does it happen?

## Practice
Build a plain HTML/CSS/TS page that calls your Library API, then reproduce and fix a CORS error in ASP.NET Core.

Put your code in `../solutions/m3-t02/` and your own notes in `../notes/m3-t02.md`.
