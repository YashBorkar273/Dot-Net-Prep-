## Why this matters
Interviewers use OOP and SOLID to judge whether you can design code, not just write it.

## Topics to cover
- [ ] Encapsulation, inheritance, polymorphism, abstraction
- [ ] Abstract class vs interface (including default interface methods)
- [ ] Overloading vs overriding, virtual/override/new/sealed
- [ ] Composition over inheritance
- [ ] Each SOLID principle with a real violation and its fix

## Interview check: you must be able to answer
- Abstract class or interface: how do you decide?
- Give a real example of a Liskov Substitution violation.
- How does Dependency Inversion relate to ASP.NET Core's DI container?
- What is the difference between `new` and `override` on a method?
