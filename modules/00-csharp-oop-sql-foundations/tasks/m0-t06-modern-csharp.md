## Why this matters
Interviewers check whether you write current C#, not C# from 2015.

## Topics to cover
- [ ] Nullable reference types and the `?`/`!` operators
- [ ] Records and with-expressions
- [ ] Pattern matching (switch expressions, property patterns)
- [ ] init, required, primary constructors
- [ ] File-scoped namespaces, global usings

## Interview check: you must be able to answer
- What problem do nullable reference types solve, and do they prevent NullReferenceException at runtime?
- When would you choose a record over a class?
- Rewrite an if/else chain as a switch expression.

## Practice
