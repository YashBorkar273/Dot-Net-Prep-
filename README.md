## How this repo works
- Each module has a folder with `tasks/` (one doc per task), `notes/`, `solutions/` and `test/`.
- A task is ✅ only when its completion criteria are met **in a session with Claude**: interview questions answered without hints, practice scored 7/10+.
- A module is ✅ only when all its tasks are ✅ and the module test is passed.
- Code is reviewed against [docs/review-rubric.md](docs/review-rubric.md). Feedback is blunt by design.

## Using this with Claude
- **Claude Code**: `CLAUDE.md` is read automatically. Claude edits the files and suggests a commit message.
- **claude.ai Project**: paste `CLAUDE.md` into the project instructions and upload `PROGRESS.md`, `learner-profile.md` and the current module's files to project knowledge. Claude gives you updated files at the end of each session; replace them and commit.
- **Any new chat**: start with "Resume my .NET prep" and attach `PROGRESS.md` if Claude can't read the repo.
